This is an osu! lazer gamemode/ruleset that automatically updates gamemodes made by me on exit so you don't have to manually grab the dlls every update. It does not show any notifications when gamemodes are updated, just restart your client. Support for external rulesets not created by Zankai LLC is also included, but I cannot guarantee it will work for every mode because it depends on how they format their releases.

This updater will be configured to download and keep all the gamemodes I make for osu! lazer simply.

**To install**, just unzip the contents of the release that corrresponds to your operating system into your rulesets directory.

Currently, the only ruleset provided by default is osu!sticks which can be found here: https://github.com/zanthous/Sticks

I'm planning on creating another ruleset sometime soon
